# 명리 감수 요청서 (M3 베타)

감수자에게 두 가지를 부탁합니다. **① 계산 기준 4가지 결정**과 **② 경계 케이스 30행 확인**입니다. 해석 문장 검수는 콘텐츠가 216룰 규모로 채워진 뒤 따로 요청합니다.

## ① 계산 기준 결정

현재 기본값으로 동작 중이며, 결정되면 표의 "바꿀 곳"만 수정하고 골든 테스트를 다시 돌립니다.

| # | 항목 | 현재 기본값 | 선택지 | 바꿀 곳 |
|---|---|---|---|---|
| 1 | 자시 기본값 | 23시에 날짜 변경 (`UNIFIED`) | 야자시·조자시 구분 (`SPLIT`) | 앱 입력 화면 기본값 (`apps/mobile/src/app/index.tsx`) |
| 2 | 경도 보정 기본값 | ON — 출생지 지방평균시 (서울 −32분) | OFF — 당시 표준시 (서머타임만 제거) | 같은 파일 |
| 3 | 대운수 반올림 · 나이 표기 | 절입까지 일수 ÷ 3을 반올림, 최소 1 · 만 나이 | 내림 / 나머지 2일 이상 올림 · 세는나이 | `apps/api/src/engine/index.ts` 대운 계산 |
| 4 | 오행 · 신강약 가중치 | 월지 오행 ×1.5 · 신강약 월지30 일지15 월간12 시간12 시지12 연간10 연지9, 구간 24/44/55/74 | 감수자 제안값 | `apps/api/src/engine/tables.ts` |

## ② 경계 케이스 확인

`apps/api`에서 `npm run review:sheet`를 실행하면 `out/expert-review.csv`가 만들어집니다. 10개 케이스 × 3가지 계산 방식 = 30행이며, 엑셀에서 바로 열립니다.

| 열 | 내용 |
|---|---|
| 사주 (시 일 월 연) | 엔진 산출 8자 |
| 대운 | 방향 · 대운수 · 정밀 시작 나이 · 첫 대운 |
| 오행 가중 비율 · 신강약 · 격국 | §4.5 공식 결과 |
| **판정 · 올바른 값 · 의견** | 감수자가 채우는 칸 |

케이스: PRD 예시, 입춘 30분 전/후, 23:30 출생, 00:10 출생, 1987 서머타임, 1960 UTC+8:30 시기, 음력 윤달, 시간 모름·입춘일, 부산 06:59(경도 보정으로 시지가 바뀌는 경계).

"다름"으로 표시된 행은 골든 테스트(`apps/api/test/engine.test.ts`)에 기대값으로 추가한 뒤 엔진을 고칩니다.

## ③ 해석 문장 초안 검수

`apps/api/content/`의 해석 문장은 **초안**입니다. 룰 185개 · 문장 약 190개로, 어떤 사주든 탭마다 요약 · 세부 풀이 · 조언이 비지 않도록 조건을 나눠 두었습니다.

| 파일 | 내용 | 감수 포인트 |
|---|---|---|
| `rules.csv` | 어떤 조건일 때 어떤 문장을 낼지 (`all` · `any` · `none` 열에 조건 코드) | 조건과 해석이 명리적으로 맞는지 (예: 재성 3개 이상 + 신약 → 재다신약) |
| `templates.csv` | 실제 문장 (`{{…}}`는 이름 · 간지 · 비율로 바뀜) | 표현이 과하거나 단정적이지 않은지, 용어 풀이가 정확한지 |

작성 원칙 (PRD §5.7): 질병 · 사고 · 이혼 같은 확정 표현을 쓰지 않고, 부정적인 내용 뒤에는 조언을 둡니다. 문장을 고친 뒤 `npm run rules:import`로 검증하면 빈 섹션 비율이 함께 나옵니다.
